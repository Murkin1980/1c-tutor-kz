# Official UI research

Этот каталог — единственный источник правды для высокоточных учебных симуляторов. Материал нельзя использовать в коде, пока паспорт версии не содержит официальный источник, дату наблюдения и статус методической проверки.

## Правила

- сохранять только обезличенные материалы, полученные законным доступом владельца;
- не хранить ИИН/БИН, ФИО, счета, документы, ЭЦП, логины и пароли;
- отделять наблюдаемый факт от предположения;
- фиксировать viewport, масштаб, версию и дату;
- описывать обязательные учебные отличия;
- после изменения портала добавлять запись в журнал отличий.

До утверждения паспорта интерфейса приложение использует только явно обозначенные placeholder-компоненты.
