# SECURITY, LICENSING AND TRAINING LIMITS — 1C Tutor KZ

Обновлено: 2026-08-15.

## 1. Training data

- использовать только вымышленные реквизиты и хозяйственные операции;
- не просить реальные ИИН/БИН, банковские счета, ЭЦП, NCALayer keys, пароли и секреты;
- не загружать реальные бухгалтерские документы в Stage 1B;
- seed/reset state должен быть полностью учебным и детерминированным;
- telemetry не должна содержать значения чувствительных полей.

## 2. Training Workspace

На каждой рабочей области постоянно видна маркировка:

`УЧЕБНАЯ СРЕДА — НЕ 1С`

Training Workspace является независимой учебной репликой ограниченных workflow и не является бухгалтерской системой, официальной конфигурацией или способом вести реальный учет.

Запрещено:
- создавать форму входа, похожую на официальный сбор credentials;
- принимать реальные ключи/пароли;
- скрыто вызывать реальные 1С/государственные endpoints;
- автоматически подписывать/отправлять документы;
- заявлять pixel-perfect/official fidelity без основания.

## 3. Brand / intellectual property

- название 1С использовать только для честного описания предмета обучения/совместимости;
- не использовать официальный логотип без разрешения;
- не создавать впечатление официального партнёрства;
- не распространять конфигурации 1С, закрытые учебные материалы или proprietary assets;
- визуальная реплика должна воспроизводить необходимые interaction patterns, а не копировать брендовые активы;
- юридически безопасные deliberate differences фиксируются в Interface Passport.

## 4. Knowledge Atlas copyright policy

`knowledge/1c/` не является зеркалом 1С:ИТС.

Допустимо хранить:
- source URL/metadata;
- собственные структурированные факты и краткие summaries;
- configuration/version/date provenance;
- короткие цитаты только когда действительно нужны и допустимы;
- ссылки на локальные исследовательские артефакты, если права на хранение проверены.

Недопустимо массово копировать:
- страницы ИТС;
- книги/руководства;
- платные курсы;
- транскрипты видео;
- наборы скриншотов;
- иконки/стили/ассеты, права на которые не подтверждены.

Не обходить paywall/login/license controls. Для источника с ограниченным доступом хранить метаданные и access class.

## 5. Accounting / regulatory accuracy

Налоги, зарплата, обязательная отчетность, проводки и юридически значимые правила публикуются только после:
- exact Kazakhstan localization evidence;
- актуальной version/date проверки;
- проверки практикующим бухгалтером/методистом, когда это требуется.

Atlas может содержать исследовательскую запись с пометкой `research_only`, но Tutor не должен представлять её как нормативную истину.

## 6. Web security Stage 1B

- CSP self-first;
- `frame-ancestors 'none'`;
- отсутствие внешней 1C iframe dependency;
- no secrets in frontend/repo;
- `npm run check:secrets` mandatory;
- dependency/security review;
- browser repositories contain only training/progress data.

RLS/private storage/rate limiting становятся обязательными только после отдельного server-persistence stage.

## 7. Real 1C transfer stage

Если позднее появляется режим переноса навыка в реальную/демо 1С:
- он отделён от core Training Workspace;
- пользователь сам авторизуется на официальной стороне;
- Tutor не получает credentials;
- нет DOM automation/autoclick/signing;
- действия с реальными данными явно предупреждаются и не выполняются в рамках обычного tutorial flow.
