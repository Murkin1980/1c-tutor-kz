# Первая инструкция для Codex: каркас интерактивного тренажёра

## Цель итерации

Создать рабочий frontend-прототип 1C Tutor KZ, который можно задеплоить на Cloudflare Pages и открыть с любого компьютера.

## Перед началом

Прочитай:

- `FOUNDATION.md`;
- `README.md`;
- `CODER_INSTRUCTION.md`;
- `PRODUCT_REQUIREMENTS.md`;
- `ARCHITECTURE.md`;
- `COURSE_STRUCTURE.md`.

Подтверди в отчёте, что конфликтов с фундаментом нет.

## Задачи

1. Инициализируй React + TypeScript + Vite.
2. Включи strict TypeScript.
3. Подключи React Router.
4. Настрой Tailwind CSS.
5. Создай общий layout.
6. Создай страницы:
   - лендинг;
   - dashboard;
   - страница курса;
   - экран урока;
   - профиль-заглушка.
7. Создай mock-курс минимум из 2 модулей и 5 уроков.
8. Реализуй типы проверки:
   - self_confirm;
   - single_choice;
   - number.
9. Сохраняй прогресс в localStorage через отдельный repository/interface, чтобы потом заменить его на Supabase.
10. Реализуй кнопку открытия 1С в новой вкладке с `noopener,noreferrer`.
11. До открытия ссылки сохраняй текущий шаг.
12. Добавь три уровня подсказок.
13. Добавь экран итогов урока.
14. Добавь предупреждение об учебной базе.
15. Добавь unit-тесты и один Playwright e2e-сценарий.
16. Подготовь `_redirects` и `_headers` для Cloudflare Pages.
17. Добавь GitHub Actions для lint, typecheck, test и build.
18. Создай `SESSION_NOTES.md`.

## UI-направление

- светлый, спокойный интерфейс;
- крупная типографика;
- минимум отвлекающих элементов;
- боковая панель шагов на desktop;
- нижняя навигация на мобильном;
- кнопка «Открыть 1С» визуально выделена;
- не копировать визуальный стиль 1С.

## Критерии приёмки

- `npm run dev` запускает приложение;
- все маршруты работают после прямого обновления страницы;
- прогресс восстанавливается после перезагрузки;
- внешний сервис открывается отдельно;
- правильный ответ завершает урок;
- неправильный ответ не стирает введённые данные;
- подсказки открываются последовательно;
- приложение адаптивно;
- build можно развернуть на Cloudflare Pages;
- тесты проходят.

## Не делать в этой итерации

- Supabase;
- реальную регистрацию;
- AI;
- распознавание скриншотов;
- iframe;
- платёжную систему;
- сложную админку;
- интеграцию с API 1С.
