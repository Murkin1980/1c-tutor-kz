# Glossary — draft v0.1

| English term | Russian explanation | Caution |
| --- | --- | --- |
| Bookkeeping | Ведение бухгалтерских записей/учёта операций | Not automatically tax preparation |
| Bookkeeper | Специалист по текущему учёту | Not equal to CPA |
| Chart of Accounts | План счетов | US account categories may differ from KZ |
| General Ledger | Главная книга | Entry-level foundation |
| Debit / Credit | Дебет / кредит | Context-dependent, not synonyms for inflow/outflow |
| Accounts Receivable (AR) | Дебиторская задолженность | Customers owe the company |
| Accounts Payable (AP) | Кредиторская задолженность | Company owes vendors |
| Invoice | Счёт клиенту | Not necessarily paid |
| Bill | Счёт поставщика | Not the same as expense payment |
| Bank Reconciliation | Сверка банковских операций/остатка | Requires reconciliation of timing differences |
| Matching | Сопоставление банковской транзакции с записью | Avoid duplicate income |
| Profit and Loss (P&L) | Отчёт о прибылях и убытках | Not equal to cash flow |
| Balance Sheet | Баланс | Assets = liabilities + equity |
| Cash Basis | Кассовый метод | Distinguish from accrual |
| Accrual Basis | Метод начисления | Revenue/expense timing differs |
| Cleanup | Исправление ошибок в учёте | Scope and price based on diagnostics |
| Catch-up | Восстановление пропущенных периодов | Requires source documentation |
| Month-end Close | Закрытие месяца | Must include review and documentation |
| CPA | Certified Public Accountant | License has state-specific regulation |
| W-9 / 1099-NEC | Документы по идентификации/отчётности определённых выплат | Escalate filing/tax interpretation |
