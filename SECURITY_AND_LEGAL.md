# Безопасность, лицензирование и учебные ограничения

## 1. Данные

- использовать только вымышленные реквизиты;
- не загружать реальные счета, ЭСФ, банковские выписки и договоры в пилот;
- предупреждать пользователя перед загрузкой снимка;
- рекомендовать скрывать ИИН/БИН, банковские счета, телефоны и адреса;
- настроить удаление снимков пользователем;
- задать срок хранения учебных снимков.

## 2. Учебная база

На каждом уроке показывать предупреждение:

> Выполняйте задание только в отдельной учебной базе. Не используйте рабочую бухгалтерскую базу без резервной копии и согласования с бухгалтером.

## 3. Бренд 1С

- название 1С использовать только для описания совместимости и предмета обучения;
- не использовать официальный логотип без разрешения;
- не создавать впечатление официального партнёрства;
- добавить дисклеймер о независимом учебном продукте;
- не распространять конфигурации и закрытые учебные материалы;
- ссылки вести на официальные ресурсы или лицензированного провайдера.

## 4. Бухгалтерская точность

Материалы по налогам, учётной политике, отчётности и законодательству Казахстана должны пройти проверку практикующим бухгалтером или официальным методистом перед публикацией.

Каждый урок должен содержать:

- версию конфигурации, на которой проверялся сценарий;
- дату методической проверки;
- автора/проверяющего;
- отметку о возможном изменении интерфейса или требований.

## 5. Web security

- CSP;
- RLS;
- private Storage;
- rate limiting для AI/API;
- CAPTCHA только при реальной необходимости;
- защита admin routes серверной ролью, а не только UI;
- журнал админских изменений;
- зависимости обновлять через автоматические security PR.
